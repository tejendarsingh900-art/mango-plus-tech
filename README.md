# Mango Plus Tech

Premium digital agency website and MySQL-backed content management dashboard built with Next.js 15, React 19 and TypeScript.

## Local development

1. Copy `.env.example` to `.env.local` and configure MySQL.
2. Create the database named `mango_plus_tech`.
3. Run `npm install`.
4. Run `npm run dev -- -p 5445`.
5. Open `http://localhost:5445/admin/setup` to create the first Super Admin.

The application creates its required CMS tables automatically on first use.
